# Issue Tracker: Local Markdown

Issues and tasks for this repository are tracked locally as Markdown files in the .scratch/ directory.

## Layout

- Each feature or task area has its own directory: .scratch/<feature>/
- Individual issues or task specs are Markdown files within that directory: .scratch/<feature>/<issue-name>.md
- Active drafts and work-in-progress notes live alongside task files.

## Workflow Conventions

- **Creating an issue**: Write a new Markdown file under .scratch/<feature>/ describing the problem, acceptance criteria, and plan.
- **Listing issues**: List files in .scratch/ and its subdirectories.
- **Updating status**: Edit the Markdown file directly (e.g. check off task checkboxes - [x]).
- **Archiving / Closing**: Move completed feature folders to .scratch/archive/<feature>/ or delete when done.
