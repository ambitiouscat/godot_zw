## Purpose

Provides native engine viewport screenshot capturing and game runtime log streaming to enable closed-loop visual QA and automated diagnostics.

## ADDED Requirements

### Requirement: Native Viewport Screenshot Capture
The Godot MCP Server SHALL provide an in-engine viewport capture mechanism that extracts real rendering viewport frames when requested with game or viewport target parameters.

#### Scenario: Capturing Game Viewport
- **WHEN** client invokes 	ake_screenshot or get_game_screenshot with iewport:  game or source: game
- **THEN** system captures the live RenderingServer viewport image and saves it to the specified project path as a PNG file.

#### Scenario: Fallback to Editor UI Surface
- **WHEN** client invokes 	ake_screenshot without game viewport parameters while the editor is active
- **THEN** system captures the editor surface and returns file path and dimensions.

### Requirement: Game Runtime Output Log Buffering
The Godot MCP Server SHALL capture and buffer standard output and error messages generated by the running game instance.

#### Scenario: Reading Game Runtime Logs
- **WHEN** client invokes get_output_log with source: game while a game is or was running
- **THEN** system returns the buffered log lines emitted by the game process.
